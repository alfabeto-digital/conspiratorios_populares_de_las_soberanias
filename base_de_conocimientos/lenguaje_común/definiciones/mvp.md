# MVP

← [Lenguaje común](../lenguaje_común.md)

MVP (Minimum Viable Product) es la versión más simple de un producto que ya resulta útil para quienes lo usan. Es un concepto del desarrollo de software que prioriza entregar valor pronto sobre construir algo perfecto. Es el origen conceptual de [MIDV](midv.md), la Mínima `Interfaz` Digital Viable, que traslada esa idea desde el producto hacia la `interfaz` de las `memorias`.
