# Docker

← [Lenguaje común](../lenguaje_común.md)

Plataforma para ejecutar aplicaciones en contenedores: entornos aislados que incluyen todo lo que una aplicación necesita para correr (código, dependencias, configuración). En la `midu`, el `computador` desechable de la Ruta B puede usar Docker Compose para orquestar sus servicios. Su alternativa sin root es [Podman](podman.md).

La descripción completa está en [Virtualización](../../midu/servicios/virtualización.md).
