# Matrix

← [Lenguaje común](../lenguaje_común.md)

Protocolo abierto y [federado](federacion.md) de mensajería instantánea: permite chat, llamadas y videollamadas en tiempo real entre servidores independientes. Dendrite es la implementación de servidor Matrix que usa la `midu`, interoperable con otros servidores Matrix.

La descripción completa está en [Dendrite](../../midu/servicios/dendrite.md).
