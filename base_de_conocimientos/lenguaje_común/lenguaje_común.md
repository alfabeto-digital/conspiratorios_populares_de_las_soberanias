# Lenguaje común

← [Inicio](../../README.md#el-lenguaje-común)

Definiciones de los términos técnicos usados en esta documentación. Cada término tiene su propia nota en [definiciones/](definiciones/). Si encuentras una palabra que no entiendes, probablemente está aquí.

## A

- [ACME](definiciones/acme.md): certificados TLS automáticos
- [age](definiciones/age.md): cifrado de archivos con clave pública
- [Authelia](definiciones/authelia.md): autenticación SSO y segundo factor

## C

- [Caddy](definiciones/caddy.md): servidor web y proxy inverso
- [Certificado TLS](definiciones/certificado-tls.md): la identidad cifrada de un servidor

## D

- [DNS](definiciones/dns.md): el directorio de nombres de internet
- [Docker](definiciones/docker.md): contenedores de aplicaciones

## F

- [Federación](definiciones/federacion.md): servidores independientes que se comunican
- [Flake](definiciones/flake.md): configuración y dependencias de NixOS

## I

- [IMAP](definiciones/imap.md): recepción y sincronización de correo
- [initrd](definiciones/initrd.md): sistema mínimo del arranque
- [IP](definiciones/ip.md): la dirección de un dispositivo en internet
- [ISP](definiciones/isp.md): el proveedor de acceso a internet

## L

- [Let's Encrypt](definiciones/lets-encrypt.md): autoridad de certificados gratuita
- [LUKS](definiciones/luks.md): cifrado de disco completo

## M

- [Matrix](definiciones/matrix.md): mensajería federada
- [MIDV](definiciones/midv.md): Mínima `Interfaz` Digital Viable
- [MITM](definiciones/mitm.md): un tercero que se interpone en la comunicación
- [Módulo NixOS](definiciones/modulo-nixos.md): una parte del sistema en un archivo `.nix`
- [MVP](definiciones/mvp.md): producto mínimo viable

## N

- [NixOS](definiciones/nixos.md): Linux declarativo y reproducible
- [NVMe](definiciones/nvme.md): disco de estado sólido de alta velocidad

## P

- [P2P](definiciones/p2p.md): comunicación directa entre dispositivos
- [Podman](definiciones/podman.md): contenedores sin privilegios de root
- [PostgreSQL](definiciones/postgresql.md): base de `datos` relacional
- [Principio de menor privilegio](definiciones/principio-de-menor-privilegio.md): solo los permisos necesarios

## R

- [Registrador de dominio](definiciones/registrador-de-dominio.md): quién gestiona un nombre de dominio
- [Reverse proxy](definiciones/reverse-proxy.md): el intermediario que reparte el tráfico
- [Rollback](definiciones/rollback.md): volver a una configuración anterior

## S

- [SMTP](definiciones/smtp.md): envío de correo entre servidores
- [sops](definiciones/sops.md): secretos cifrados en git
- [SSH](definiciones/ssh.md): acceso remoto cifrado
- [SSO](definiciones/sso.md): inicio de sesión único

## T

- [TLS](definiciones/tls.md): cifrado de las comunicaciones en internet
- [TOTP](definiciones/totp.md): segundo factor de seis dígitos

## U

- [UPS](definiciones/ups.md): alimentación eléctrica ininterrumpida
- [UUID](definiciones/uuid.md): identificador estable de un disco

## V

- [VPS](definiciones/vps.md): servidor virtual con IP pública

## W

- [WireGuard](definiciones/wireguard.md): túnel VPN cifrado

## Z

- [Zero Trust](definiciones/zero-trust.md): no confiar en ningún componente por defecto
